
# AI-Powered Personalized Learning Portal

## Project Overview
The AI-Powered Personalized Learning Portal is a web-based platform designed to provide students with a personalized learning experience using Artificial Intelligence.

## Objectives
- Provide personalized learning recommendations.
- Help students understand difficult topics using AI.
- Track student learning progress.
- Provide quizzes and assessments.

## Key Features
1. User Authentication
2. Student Dashboard
3. Course Management
4. Lesson Management
5. Quiz and Assessment
6. AI Tutor
7. Personalized Recommendations
8. Progress Tracking
9. Notes and Bookmarks

## Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- AI Integration: Gemini API
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub
